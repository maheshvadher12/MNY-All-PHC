# MNY Print – Android App (બધા PHC માટે)

`Lab_Report_Final_for_all_phc.html` ને Android એપમાં ફેરવેલ પ્રોજેક્ટ (Google Drive અપલોડ વગર).

## APK બનાવવી (GitHub)
1. બધી ફાઇલો (app, gradle, .github, build.gradle, settings.gradle, gradle.properties) repository માં અપલોડ કરો.
2. Actions → Build APK → Run workflow → લીલો ટીક આવે ત્યારે Artifacts માંથી LabReport-apk ડાઉનલોડ કરો.
3. ઝીપ Extract કરી app-debug.apk ફોનમાં Install કરો.

## એપમાં શું છે
- ઇન્ટરફેસ, લુક, સ્પ્લેશ સ્ક્રીન, PHC Info ડાયલોગ, બધા ટેસ્ટ/ફંક્શન HTML ફાઇલ મુજબ જ.
- A4 રિપોર્ટ ફોનની પહોળાઈ મુજબ ફિટ (Portrait), ઝૂમ કરી શકાય.
- Print Report: ફોનનું Print ડાયલોગ (પ્રિન્ટર / Save as PDF).
- Save PDF: Downloads ફોલ્ડરમાં.
- Send to WhatsApp: Contact નંબર જરૂરી; PDF (HIV Consent વગર) અટેચ થઈ તે ચેટ ખૂલે.

## PHC માહિતી
એક વાર PHC Info ભર્યા પછી તે ફોનમાં સેવ રહે છે (એપ બંધ કરીએ તો પણ). ફેરફાર કરવો હોય તો ઉપરના **PHC Info** બટનથી બદલો.
